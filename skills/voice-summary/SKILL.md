# 음성 요약 (전사 → SRT → Markdown 요약)

녹음을 내 컴퓨터에서만 전사하고(외부 업로드 없음), 시간 정보가 있는 SRT와 읽기 좋은 요약을 만든다.

## 준비 확인
`scripts/transcribe.sh`가 필요한 도구를 검사하고, 없으면 설치 명령을 알려준다.
- `ffmpeg` (brew install ffmpeg)
- `whisper-cli` (brew install whisper-cpp)
- 모델 `~/.cache/whisper-cpp/ggml-small.bin` (약 466MB, 한국어에는 small 이상 권장)
  다른 모델은 환경변수 `WHISPER_MODEL`로 지정한다.

## 절차
1. **용어집 만들기** — 녹음 주제와 고유명사(서비스명, 사람 이름, 영문 도구명)를 한 문장으로 적는다.
   예: `"개인 기억 에이전트 기획 회의. ChatGPT, Codex, Claude Code, GitHub, MCP, 기술 스택."`
   용어집이 없으면 ChatGPT→"채치 BT", GitHub→"기토브"처럼 오인식이 많아진다.
2. **전사**
   ```bash
   skills/voice-summary/scripts/transcribe.sh <녹음파일> <출력폴더> "<용어집>"
   ```
   결과: `<출력폴더>/<파일명>.txt`, `<파일명>.srt`
3. **전사 읽기** — txt 전체를 읽는다. 문맥상 오인식이 의심되는 단어를 찾는다.
4. **요약 작성** — `<출력폴더>/<파일명>_요약.md`를 아래 형식으로 저장한다.
   SRT의 시간 정보를 근거로 붙인다. 녹음에 없는 내용은 쓰지 않는다.
5. **확인** — 요약·SRT 파일을 열어 내용·순서·시간이 녹음과 맞는지 확인하고, 결과 경로를 알린다.

## 요약 형식
```markdown
# <녹음 제목> 요약

> 원본: <파일명> · 길이 <m분 s초> · 전사: whisper-cpp small

## 한 줄 요약
## 주요 내용
- [00:00] ...
## 결정된 것
## 할 일
| 할 일 | 담당 | 기한 | 근거 시간 |
## 일정
## 전사 오인식 의심
| 시간 | 전사 | 추정 | 이유 |
```
- 담당·기한이 녹음에 없으면 "미정"으로 쓴다.
- 오인식 추정은 원문 SRT를 고치지 않고 이 표에만 적는다.

## 실제로 확인한 것 (2026-10-27)
- 61초·36초 한국어 녹음 2개에서 전사 각 약 7초 (Apple Silicon, small 모델).
- 용어집 적용 시 영문 도구명은 정확히 표기됐고, "기억→기업" 같은 동음 오인식은 남았다 → 4단계 표로 처리.
