# Mnemo 디자인 시스템

**분위기:** 모던·미니멀·단정. 흰 여백이 주인공이고 색은 포인트 하나(인디고)만 쓴다.
기억 데이터가 읽히는 것이 먼저이고, 장식은 줄인다.

## 사용 방법
1. `assets/tokens.css`를 결과물 폴더에 복사하고 `<link rel="stylesheet" href="tokens.css">`로 불러온다.
   색·간격·글꼴은 반드시 CSS 변수(`var(--accent)` 등)로 쓰고 hex 값을 새로 만들지 않는다.
2. 화면 구성 규칙(아래)을 따른다.
3. `assets/example.html`을 열어 컴포넌트 모양과 비교한다.
4. 라이트·다크 모드(`prefers-color-scheme`) 둘 다에서 확인한다.

## 핵심 값
| 항목 | 값 |
| --- | --- |
| 글꼴 | Pretendard Variable (본문 15px / 제목 24·17px, 자간 -0.02em) |
| 배경 / 면 / 선 | `--bg` #fff · `--surface` #f7f7f8 · `--border` #e6e6ea |
| 글자 | `--text` #18181b · 보조 `--text-2` · 메타 `--text-3` |
| 포인트 | `--accent` #4f46e5 (주 버튼, 선택된 칩, 링크) — 화면당 주 버튼 1개 |
| 비공개 표시 | `--private` 호박색 (`.chip-private`) — 민감한 기억에만 사용 |
| 모서리 | 6 / 10 / 14px (`--r-sm/md/lg`) |
| 간격 | 4의 배수 (`--s-1`~`--s-7`) |

## 컴포넌트
- 버튼: `.btn`, `.btn-primary`, `.btn-ghost`, `.btn-danger` (높이 36px)
- 입력: `.input` (focus 시 accent 테두리)
- 카드: `.card` — 기억 1개 = 카드 1개. 상단에 종류 칩 + 메타(날짜·출처), 본문은 그대로.
- 칩: `.chip`, `.chip.on`/`aria-pressed="true"`(선택), `.chip-private`

## 화면 구성 규칙
- 본문 최대 폭 760px, 가운데 정렬, 좌우 여백 16px 이상 (모바일 가로 스크롤 금지).
- 위에서 아래로: 제목 → 입력/검색 → 필터 칩 → 목록.
- 아이콘·그라데이션·그림자 장식은 쓰지 않는다. 구분은 선(`--border`)과 여백으로 한다.
- 빈 상태·오류 상태 문구를 반드시 만든다 (예: "아직 기억이 없어요. 첫 기억을 추가해 보세요.").

## 확인 기준
- 새 화면이 `example.html`과 같은 색·글꼴·모서리·간격으로 보이는가.
- tokens.css에 없는 색이 쓰이지 않았는가 (`grep -E '#[0-9a-f]{3,6}'`로 확인).
- 다크 모드에서 글자가 읽히는가.
